# Kubb — OPCIONAL

**Este documento só se aplica se o usuário pediu explicitamente para configurar Kubb em alguma área** (ex.: "configurar kubb em fluxos"). Por padrão, o projeto não usa Kubb — a pasta `app/core/kubb/` existe pronta mas está inerte (sem dependências instaladas). O track padrão de acesso à API é o tradicional (`Repository` + `AxiosHttpClient`, ver `references/camadas.md`).

## Arquivos gerados (proibido editar)

**NUNCA** altere arquivos gerados pelo Kubb. Qualquer mudança manual será sobrescrita na próxima geração.

### O que é proibido editar

Tudo dentro de `generated/` (o local exato depende de onde a spec da área vive sob `app/` — este projeto não força uma pasta `modules/{area}/generated/`):

- `clients/` — funções de chamada à API
- `hooks/` — hooks Vue Query (`use*`)
- `types/` — tipos TypeScript
- `zod/` — schemas de validação
- `schemas/` — JSON schemas
- `index.ts` e demais barrels gerados

Arquivos gerados contêm o cabeçalho `Generated by Kubb (https://kubb.dev/)` — **não edite**.

### O que fazer em vez disso

1. **Alterar a API** → edite o `docs/api.yaml` correspondente
2. **Regenerar o código** → na raiz do projeto:
   ```bash
   pnpm run generate:<nome>
   ```
3. **Consumir no frontend** → importe de `generated/` nos componentes Vue (ex.: hooks, types, clients)

Se precisar de lógica customizada (transformação de dados, composable com regras de negócio), crie arquivos **fora** de `generated/` — nunca dentro.

## Ativação (primeira vez no projeto)

1. Instalar as dependências (peça confirmação ao usuário antes de rodar):
   ```bash
   pnpm add -D @kubb/cli @kubb/plugin-client @kubb/plugin-vue-query
   pnpm add @tanstack/vue-query
   ```
2. Criar `kubb.config.ts` na raiz do projeto, apontando `pluginClient({ importPath: './app/core/kubb/KubbHttpClient' })` para que o código gerado use o client da app.
3. Chamar `setupKubbClient()` (de `app/core/kubb/setupKubbClient.ts`) uma vez num plugin Nuxt — `app/plugins/kubb.ts` (`defineNuxtPlugin`). Este projeto não tem `bootstrap/createApp.ts`; Nuxt já cria/monta a aplicação.
4. Registrar `VueQueryPlugin` (de `@tanstack/vue-query`) no mesmo plugin ou em `app/plugins/vue-query.ts`, se os hooks gerados (`generated/hooks/`) forem usados.
5. Adicionar o script `generate:<nome>` no `package.json` apontando para o `docs/api.yaml` correspondente.

Ver `app/core/kubb/_OPCIONAL.md` para o mesmo passo a passo direto no código.

## Instalar novas dependências

**Nunca rode `pnpm install`, `pnpm install --frozen-lockfile`, `pnpm update` diretamente via Bash.** Em vez disso:

1. Identificar qual dependência é necessária
2. **Pedir confirmação ao usuário** antes de rodar `pnpm add <pacote>` na raiz do projeto (ou pedir para ele mesmo rodar)
3. **Aguardar confirmação** do usuário de que o comando foi executado e o pacote está disponível
4. Apenas depois, usar o pacote (imports, config, etc.) como se a instalação tivesse ocorrido

Razão: mudanças em `package.json`/`pnpm-lock.yaml` devem ser explícitas e revisáveis pelo usuário, não silenciosas.
